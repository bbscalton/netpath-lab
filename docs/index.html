Team drill (15 minutes)

1. Lab VPS

Stand up OpenSSH on a VPS you own. Prefer port 443. See the server section below.

2. Control test

On Wi‑Fi or paid data: enter VPS host, user, password → Connect. Confirm SSH works.

3. Pack APN test

Switch to pack/zero-rate SIM. Apply any method from the in-app spinner (start with SNI mismatch or full hold stack).

4. Score it

PASS: blocked or fully charged.
FAIL: unmetered success to your VPS = allowlist gap.

Lab server (sshocean)

Pre-filled in every import config. Host fr1.sshweb.site · SSH ports 22/80 · TLS 143/443 · account expires 13 Aug 2026.

See LAB_SERVER.md for port mapping and operator notes.

sudo apt update && sudo apt install -y openssh-server
sudo tee /etc/ssh/sshd_config.d/netpath-lab.conf <<'EOF'
Port 443
PasswordAuthentication yes
PubkeyAuthentication yes
AllowTcpForwarding yes
PermitTunnel no
EOF
sudo systemctl restart ssh
sudo ufw allow 443/tcp
sudo adduser netpath

In the app: host = VPS public IP, port = 443, username/password = lab user.

For SNI mismatch: Custom SNI = a pack-like hostname; dial host stays your VPS IP.

For full TLS wrap (method 8): terminate TLS with stunnel/sslh in front of sshd.

For WebSocket / Trojan / HTTP/2 fronts (methods 13–16): sshd on 443 must accept leading non-SSH bytes before the SSH banner, or use a simple strip-and-forward proxy in the lab.

For doc-only drills 18–25 (Reality, VMess, Shadowsocks, Hysteria, etc.): deploy the matching server on your VPS with Xray/sing-box — not bundled in the APK.
